# Public search feed v1

After deployment: https://anuragrathor92-crypto.github.io/sarkarialert/data/public-search.json

Read-only JSON, generated by the existing site builder from published verified records. No credentials or private review metadata. This is a static public feed, not a server-side query API; consumers fetch it and filter locally. Expired records are excluded at build time; consumers should also honor deadline and application status at read time. A source review date is not a new independent official verification. Links marked pending have no applyUrl in the feed. Scheme records have no applyUrl. Use the detail URL for current instructions and official notice. Do not infer personal eligibility from keyword matches. The generatedOn value is build time, not the official notice date.

Search page: https://anuragrathor92-crypto.github.io/sarkarialert/assets/smart-search.html?q=UPSC

Hindi/English keyword and qualification matching is deterministic, not a language model. No paid API or external search service.
